# CAMCREW- Frontend

This is the frontend app for the CAMCREW project, built with React and Vite.

## Tech Stack

- React
- Vite
- Tailwind CSS
- React Router
- Axios

## Getting Started

### 1. Install dependencies

```bash
npm install
```

### 2. Run development server

```bash
npm run dev
```

### 3. Build for production

```bash
npm run build
```

### 4. Preview production build

```bash
npm run preview
```

## Lint
